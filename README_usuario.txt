Obrigado por instalar o ExtratorDataSul NF-e!
Leia as instrucoes abaixo antes de usar o aplicativo.


------------------------------------------------------------
  1. PRE-REQUISITO — VPN
------------------------------------------------------------

O ExtratorDataSul so consegue se conectar ao sistema DataSul
atraves da VPN corporativa.

ANTES DE ABRIR O APLICATIVO, certifique-se de que a VPN
esta ativa. Sem ela, o aplicativo nao ira conectar.


------------------------------------------------------------
  2. PRIMEIRO ACESSO
------------------------------------------------------------

1. Localize o atalho "ExtratorDataSul NF-e" na Area de
   Trabalho ou no Menu Iniciar.

2. Ao abrir, sera exibida uma tela de login. Informe seu
   usuario e senha do sistema DataSul.

3. Marque "Salvar credenciais com seguranca" para nao
   precisar digitar novamente nas proximas vezes.


------------------------------------------------------------
  3. COMO USAR
------------------------------------------------------------

1. Clique em "Filtros" para expandir o painel de filtros.

2. Informe o periodo desejado (Data De / Data Ate).

3. Ajuste os filtros de Estabelecimento, Serie e NF
   conforme necessario.

4. Clique em "EXECUTAR".

5. Ao concluir, o arquivo Excel sera aberto automaticamente
   (se a opcao estiver marcada em Configuracoes).


------------------------------------------------------------
  4. ARQUIVO EXCEL ACUMULATIVO
------------------------------------------------------------

O ExtratorDataSul salva todos os dados extraidos em um
unico arquivo Excel acumulativo:

  Documentos\relatorio_nfe_acumulativo.xlsx

A cada extracao, os novos registros sao adicionados ao
arquivo existente. Registros ja presentes sao ignorados
automaticamente — nao ha duplicatas.

Para alterar o caminho do arquivo, clique em
"Config" no cabecalho do aplicativo.


------------------------------------------------------------
  5. PROBLEMAS COMUNS
------------------------------------------------------------

Nao conecta ao DataSul
  -> Verifique se a VPN esta ativa e tente novamente.

Nenhum dado encontrado
  -> Verifique o periodo informado e os estabelecimentos
     selecionados.

WebView2 nao instalado
  -> Baixe e instale manualmente em:
     https://developer.microsoft.com/microsoft-edge/webview2/

Credenciais invalidas
  -> Verifique usuario e senha com o administrador do
     sistema DataSul.
